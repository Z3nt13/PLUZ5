Tick each step when done (your ticks stay in this browser). Everything below works from a browser; no install needed.

1 · Make your repository

  1. Sign in at github.com (free account).
  2. Open the template page of PLUZ5 → Use this template → Create a new repository.
  3. Name it (e.g. PLUZ5-mine), choose Public, create.

2 · Paste your repo address

Waiting for a link...

3 · Two switches in your repo (once)

  1. Settings → Actions → General → Workflow permissions: Read and write → Save.
  2. Settings → Pages → Source Deploy from a branch → Branch main, / (root) → Save. Wait 1-3 min for "site is live".

4 · Get a GitHub token (makes everything easier)

With a token the web pages can save straight to your repo, and the PC scripts can push without asking for a password.

  1. GitHub → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it PLUZ5, Expiration 90 days, Only select repositories → pick your repo.
  3. Permissions → Repository: Contents: Read and write and Workflows: Read and write. Generate.
  4. Copy the token now (shown once). Keep it secret. It goes only in .env (PC) or into the page's Connect box (memory only, never saved).

5 · Your settings file (.env, for PC / Linux use)

Copy this into .env in the unzipped folder. Add your token after GH_TOKEN=. Never upload .env.

(paste your repo link above)

6 · Pick your payloads

  1. Open the Builder or the Library.
  2. Library: tick sources you want → drag to Store (or "Add to Store"). Builder: paste repo links or Load example list.
  3. Download payload_registry.json (and PLUZ5-infos.json from the Library).

7 · Publish

  1. Upload the files: payload_registry.json into configs/, PLUZ5-infos.json into data/ (repo → Add file → Upload files → Commit).
  2. Actions → PLUZ5 Update → Run workflow. Green tick in about a minute.
  3. Open your manifest link (next step). You should see JSON, not an error.

8 · Add it to pldmgr on the PS5

(paste your repo link above)
Full pldmgr guide with check button
  1. pldmgr → Settings (gear) → Manage Sources → Add Source.
  2. Paste the link → Add.

9 · Maintain it later

  • Add sources: Library → add a repo link → drag to Store → upload both json files → run the workflow.
  • Own .elf / .bin: name it Name_v1.0.elf, put it in payloads/, run the workflow.
  • From a PC: unzip, edit .env, run PLUZ-AllStar.bat (Linux: ./pluz-allstar.sh).
  • Daily updates run by themselves. If they stop after 60 idle days, press Run workflow once.
