Share only this link. It is public by design: pldmgr on the PS5 downloads it.

Add it in pldmgr (on the PS5)

  1. Open pldmgr.
  2. Settings (gear icon) → Manage Sources → Add Source.
  3. Paste the link above → Add.
  4. Back on the main screen your store name appears with the payload list. Pick one → download → send.

If something is off

  1. Check it works says 404: the workflow has not run yet, or user/repo/branch is wrong (case matters).
  2. Shows JSON in a browser but pldmgr is empty: re-add the source; make sure the repo is Public.
  3. Entry missing: open the Actions log, look for [SKIP] lines for that name.
